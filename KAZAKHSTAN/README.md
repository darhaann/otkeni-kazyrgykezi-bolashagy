# Казахстан — прошлое, настоящее, будущее (сайт)

Лёгкий адаптивный одностраничный сайт для школьного проекта/презентации.

## Как открыть

### Вариант A (самый простой)
- Откройте `index.html` в браузере (двойной клик).

### Вариант B (рекомендуется: локальный сервер)
Иногда браузер ограничивает некоторые функции при открытии файлов напрямую, поэтому локальный сервер
удобнее.

Если у вас установлен Python:

```bash
python -m http.server 5500
```

Потом откройте `http://localhost:5500` в браузере.

## Структура проекта

- `index.html` — содержание страницы
- `css/style.css` — стили
- `js/main.js` — мобильное меню, переключатель темы, подсветка активной секции
- `images/` — изображения (пока пусто)
